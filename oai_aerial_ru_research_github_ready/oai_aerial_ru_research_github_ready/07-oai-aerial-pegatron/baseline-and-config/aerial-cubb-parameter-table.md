# Aerial cuBB Parameter Table

## Purpose

This note introduces the OAI gNB configuration parameters used in the OAI L2 + Aerial cuBB integration.

## Parameter Table

Compared with [Pegatron RU gNB config](https://github.com/Kuan-K/Metanoia_intern_kuan2026/blob/main/doc/gnb.sa.band78.273prb.fhi72.4x4-pega-1G.conf)

Most parameters are the same as the [Pegatron RU config file](https://github.com/Kuan-K/Metanoia_intern_kuan2026/blob/main/oai_aerial_ru_research_github_ready/oai_aerial_ru_research_github_ready/07-oai-aerial-pegatron/baseline-and-config/oai-gnb-parameter-table.md).
Therefore, this table only lists the parameters that are different between the Pegatron RU configuration and the Aerial cuBB configuration.

| Category         |                            Parameter |     Pegatron |       Aerial | Note                                                                                                                                                                                                                                                  |
| ---------------- | -----------------------------------: | -----------: | -----------: | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cell identity    |                          `nr_cellid` |          `1` |  `12345678L` | The NR Cell ID is different, so the UE will observe a different cell identity. This usually does not affect the RF frequency, but it affects cell identification and may influence observations related to UE registration and core network behavior. |
| UL antenna       |                 `pusch_AntennaPorts` |          `4` |          `2` | This is related to the number of RU antennas, L1-supported layers, and UL MIMO capability.                                                                                                                                                            |
| SRS              |                             `do_SRS` |          `0` | `"periodic"` | Pegatron disables SRS, while Aerial enables periodic SRS.                                                                                                                                                                                             |
| CORESET0         | `initialDLBWPcontrolResourceSetZero` |         `10` |         `12` | This affects the initial PDCCH / SIB1 search location. Since the UE must be able to decode SIB1, this setting should not be changed randomly. It must be configured together with SSB, Point A, and bandwidth.                                        |
| UE power         |                               `pMax` |         `23` |         `20` | This value is broadcast to the UE as the maximum UE transmit power limit.                                                                                                                                                                             |
| PRACH            |          `zeroCorrelationZoneConfig` |         `15` |         `12` | To be confirmed.                                                                                                                                                                                                                                      |
| PRACH power      |        `preambleReceivedTargetPower` |       `-104` |        `-96` | This defines the target received power when the UE transmits the PRACH preamble.                                                                                                                                                                      |
| PRACH retry      |                   `preambleTransMax` |          `7` |          `6` | The maximum PRACH retransmission index is different. Pegatron allows more RA preamble attempts.                                                                                                                                                       |
| PRACH ramping    |                   `powerRampingStep` |          `2` |          `1` | The power increase step for each PRACH retransmission is different.                                                                                                                                                                                   |
| Msg3 power       |                 `msg3_DeltaPreamble` |          `2` |          `1` | This is the power offset between the PRACH preamble and Msg3 PUSCH. It affects the transmit power of Msg3 after random access.                                                                                                                        |
| UL power control |                `p0_NominalWithGrant` |        `-96` |        `-90` | This is related to uplink power control for grant-based PUSCH transmission.                                                                                                                                                                           |
| PUCCH hopping    |                          `hoppingId` |          `0` |         `40` | This affects the hopping configuration used by PUCCH.                                                                                                                                                                                                 |
| PUCCH power      |                         `p0_nominal` |        `-96` |        `-90` | This is related to the nominal power setting for PUCCH transmission.                                                                                                                                                                                  |
| TDD period       |      `dl_UL_TransmissionPeriodicity` |          `5` |          `6` | `5 = ms2p5`, `6 = ms5`. Pegatron uses a 2.5 ms TDD pattern, while Aerial uses a 5 ms TDD pattern.                                                                                                                                                     |
| TDD DL slots     |                  `nrofDownlinkSlots` |          `3` |          `6` | Pegatron has 3 full DL slots, while Aerial has 6 full DL slots.                                                                                                                                                                                       |
| TDD DL symbols   |                `nrofDownlinkSymbols` |          `6` |         `10` | Pegatron has 6 DL symbols in the mixed slot, while Aerial has 10 DL symbols.                                                                                                                                                                          |
| TDD UL slots     |                    `nrofUplinkSlots` |          `1` |          `3` | Pegatron has 1 full UL slot, while Aerial has 3 full UL slots.                                                                                                                                                                                        |
| TDD UL symbols   |                  `nrofUplinkSymbols` |          `4` |          `0` | Pegatron has 4 UL symbols in the mixed slot, while Aerial has no UL symbols in the mixed slot.                                                                                                                                                        |
| SSB power        |                  `ssPBCH_BlockPower` |          `0` |        `-34` | The SSB/PBCH block power setting is different. This value should be consistent with the actual RU transmit power, gain setting, and calibration.                                                                                                      |
| L2-L1 transport  |            `MACRLCs.tr_s_preference` | `"local_L1"` |   `"aerial"` | Pegatron MAC/RLC connects directly to the local OAI L1, while Aerial MAC/RLC uses the Aerial transport path to connect to the external cuBB L1.                                                                                                       |
| Scheduler        |                 `pusch_TargetSNRx10` |        `200` |        `280` | Pegatron uses 20 dB, while Aerial uses 28 dB. Aerial requires a higher target SNR for PUSCH, which may affect UL MCS and link adaptation.                                                                                                             |
| Scheduler        |                 `pucch_TargetSNRx10` |        `200` |        `100` | Pegatron uses 20 dB, while Aerial uses 10 dB. The PUCCH target SNR is different, which may affect the reception threshold of uplink control signals.                                                                                                  |
